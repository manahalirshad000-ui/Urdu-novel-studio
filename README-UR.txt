اردو ناول اسٹوڈیو — آف لائن ورژن

شروع کرنے کا طریقہ:
1. ZIP فائل Extract All کریں۔
2. Urdu_Novel_Studio_v2 فولڈر کھولیں۔
3. index.html کو Chrome یا Edge میں کھولیں۔
4. انٹرنیٹ بند ہونے پر بھی لکھنے اور محفوظ کرنے کی سہولت کام کرتی ہے۔

اہم خصوصیات:
- باب وار لکھنے اور بغیر ابواب کے مسلسل لکھنے کے دو طریقے۔
- خودکار محفوظ کاری، متعدد ناول، ابواب کا اضافہ/نام بدلنا/حذف کرنا۔
- مناظر کی گیلری: تصویر منتخب کرکے متن میں شامل کریں۔
- سرورق کی گیلری: ناول کے لیے کور منتخب کریں۔
- ناول کے عنوانات اور کہانیوں کے ابتدائی آئیڈیاز (آف لائن)۔
- مکمل ناول PDF میں محفوظ: PDF بٹن دبائیں، پرنٹ ڈائیلاگ میں Save as PDF منتخب کریں۔
- TXT ایکسپورٹ اور JSON بیک اپ/بحالی۔

یاد دہانی:
- آپ کا ڈیٹا اسی براؤزر اور اسی ڈیوائس میں محفوظ ہوتا ہے۔ براؤزر کا ڈیٹا صاف کرنے سے پہلے Backup ضرور بنائیں۔
- PDF بنانے کے لیے براؤزر کی Print سہولت استعمال ہوتی ہے۔
- یہ آف لائن ویب ایپ ہے، Android APK نہیں۔ فون پر چلانے کے لیے بعد میں اسے HTTPS پر ہوسٹ کرکے installable PWA بنایا جا سکتا ہے۔


فون پر انسٹال کرنے کے لیے (PWA):
1) اس فولڈر کے تمام مواد کو HTTPS ویب ہوسٹنگ (مثلاً GitHub Pages) پر اپ لوڈ کریں۔
2) اپنے Tecno Pova پر Chrome میں شائع شدہ ویب ایڈریس کھولیں۔
3) مینو (تین نقطے) > Install app یا Add to Home screen منتخب کریں۔
4) ایپ پہلی بار کھلنے پر تصاویر اور فائلیں لوڈ ہونے دیں؛ پھر آف لائن موڈ آزمائیں۔
